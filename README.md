# Türkçe küfür listesi (Minecraft)

## İlke
- Yetkili `/sustur` sebeplerinin tamamı engellenir (hakaret, küfür, kısaltma, ailevi, dini, ırkçılık, cinsellik, reklam…).
- `excluded_fp.txt` / `safe_words.txt` = **sadece masum** kelimeler (yapıcam, tamam, netherite…). Küfür asla buraya konmaz.

## Dosyalar
- `kufurler_1.txt` engellenen tekil kelimeler
- `kufurler_2.txt` kalıp / leet / çok kelimeli
- `safe_words.txt` maskeleme
- `excluded_fp.txt` = safe ile aynı mantık (masumlar)

Kaynak: kufur.sk + GitHub upstream + 20 günlük sustur kategorileri.
